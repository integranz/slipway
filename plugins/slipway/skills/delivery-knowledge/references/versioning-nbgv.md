# Versioning option `nbgv` — Nerdbank.GitVersioning

- Source of truth: one `version.json` **per app** at `<app path>/version.json` (`version: "0.2"`, `publicReleaseRefSpec: ["^refs/heads/main$"]`, `pathFilters`, `release.tagName: "<app>/v{version}"`). Patch = git height counted only over commits touching the app's `pathFilters` (its path, shared inputs, its workflow files, `infra/apps/<app>`; `/…` means repository-relative, `:!` excludes). Other branches produce prerelease versions (`0.2.7-g<sha>`) that must not be deployed beyond `dev`. Verified with nbgv 3.10.94 (2026-09-17): a commit outside an app's filters leaves its height unchanged; a shared path bumps every app that lists it.
- The scaffold generates `version.json` once and afterwards refreshes only `pathFilters` and `release.tagName`; `version` belongs to humans. A repository-level `version.json` is legacy (the scaffold warns about it).
- Local: `nbgv get-version -p <app path> -v SemVer2` (tool installed with `dotnet tool install -g nbgv`, needs a .NET SDK). CI: `dotnet/nbgv@v0.5.2` with `path: <app path>` after `actions/checkout` with `fetch-depth: 0`; outputs `SemVer2`, `SimpleVersion`, `GitCommitIdShort`, `PublicRelease`, `NpmPackageVersion`, … (`setAllVars: true` exports them as `NBGV_*` env vars).
- Images are tagged with `SemVer2`; the same value is stamped into the API (`-p:InformationalVersion`) and the web bundle (`VITE_APP_VERSION`) so `/slipway:verify` can compare the running version with the tag.
- The release job runs `nbgv tag -p <app path>` (creates `<app>/v<version>` on the release commit, name from `release.tagName`) and pushes the tag; image tags stay `<semver>` because the image repository already names the app (a prerelease suffix such as `1.9-api` would make every build a SemVer prerelease); `permissions: contents: write` is required. Bump the minor by editing the app's `version.json` in a normal PR; never hand-write tags.
- Works for any repository (the demo's web app has no .NET code); the .NET SDK is only a build-time dependency of the tool.
- Exercised on `integranz/slipway-demo` (first CI release on 2026-09-15 with a root `version.json`; per-app files since the 0.13.0 cutover).
