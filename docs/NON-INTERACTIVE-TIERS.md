| **Headless onboarding (Cursor Automations + Cloud Agents API + GitHub org webhook)** | **assessed 2026-09-27 — parked by the owner (dated decision)** | would be: the first push with deployable code to a new repository of the organisation | — | — | — | — | — | Assessment (cursor.com docs, docs.github.com, Microsoft Learn, live `integranz` state, 2026-09-27): Automations have no repository-created trigger and are bound to fixed repositories (no org-wide scope); a new repository is empty at creation; GitHub webhooks cannot carry the automation webhook's API key header, so any webhook path needs a relay and would start one LLM run per push; only the Cloud Agents API (`POST /v1/agents` with `repos[{url}]`) targets an arbitrary repository.
