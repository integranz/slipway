# Cursor Automation runbook — PR review on `integranz/slipway-demo` (goal 7 tier)

Source: cursor.com/docs/cloud-agent/automations (read 2026-09-16). Automations are cloud agents that run on a trigger; they are created in the Agents window, at cursor.com/automations, or with the `/automate` skill, and billed as cloud-agent usage on a paid plan. The Integrant team seat is active (confirmed by the owner on 2026-09-16).

| Field | Value |
|---|---|
| **Name** | `adlc-demo PR review` |
| **Trigger** | Source control → **Pull request opened** and **Pull request pushed** (non-draft) |
| **Repository scope** | single repository: `integranz/slipway-demo`, any branch → `main` |
| **Who can trigger** | anyone who opens a PR on the repo (public repo; the automation runs under the team's Cursor GitHub app installation) |
| **Tools** | `Comment on Pull Request` only. No Slack, no MCP servers, no secrets: the review needs only the repository contents |
| **Prompt** | see below |
| **Output / review path** | one top-level PR comment (plus inline comments for concrete findings); a human reviews the comment and decides; the automation never approves, merges, pushes or edits files |
| **Monitoring** | run history at cursor.com/automations (status, duration, transcript); the PR comment is the visible artefact |
| **Rollback** | deactivate the automation in the dashboard; delete the comment if needed |
| **Secrets and data policy** | repository content is public; no credentials are provided to the agent; the agent must not attempt cloud, registry or Jira access (AGENTS.md tool policy applies) |

## Prompt
```
You are reviewing a pull request in integranz/slipway-demo, a repository delivered by the slipway plugin.
Read AGENTS.md and CLAUDE.md first; they define the non-negotiables and the path-scoped rules in .claude/rules/.
Review only the diff of this pull request against those rules and report as ONE top-level comment with three sections:
1. Rule violations (cite the rule file and the line of the diff): mutable image tags, secrets or tfvars/state/plan files,
   hand-edited generated files (AGENTS.md, CLAUDE.md, .claude/rules/*, .github/workflows/*, infra/**, apps/*/Dockerfile,
   nginx*.conf, compose.yaml are generated by the slipway scaffold and must be changed through the plugin templates),
   terraform apply or destroy anywhere, changes to .slipway/config.yaml that select an option marked planned or later.
2. Risks worth a human look (breaking changes to /health or /api/health, port changes, version.json edits).
3. Verdict: "No rule violations" or the list above. Do not approve, request changes, push commits or edit files.
Keep it under 30 lines. If the diff touches only .slipway/evidence/*.md, reply with a one-line "evidence-only change".
```
